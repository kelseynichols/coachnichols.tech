# coachnichols.tech

Personal website for Coach Nichols Tech, hosted on GitHub Pages.

## Local preview

```bash
python3 -m http.server 8000
# then open http://localhost:8000/
```

## Structure

- `index.html`, `about.html`, `backstory.html`, `work.html` — pages
- `css/` — styles
- `js/` — scripts
- `images/`, `fonts/` — assets
- `CNAME` — custom domain (`coachnichols.tech`)
